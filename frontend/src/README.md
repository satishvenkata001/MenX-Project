# Frontend Directory Scaffolding
- components/ : Reusable mobile-first UI components (buttons, bottom nav, filter drawer)
- pages/ : Customer storefront, checkout, and admin pages
- services/ : API client and Supabase browser client
- hooks/ : Custom React hooks (useCart, useAuth)
- context/ : Global React contexts (CartContext, AuthContext)
- utils/ : Currency formatters, helper functions
